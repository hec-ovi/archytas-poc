La posicion de cuenta de un proveedor: cuantas facturas tiene, cuanto se le compro, cuanto se
le pago, cuanto se le debe hoy y cuantos dias tiene la deuda mas vieja. Es la herramienta
para responder "cuanto le debemos a".

## proveedor
El nombre del proveedor como lo escribio la persona. Se resuelve contra el catalogo, asi que
puede venir incompleto o mal escrito.
